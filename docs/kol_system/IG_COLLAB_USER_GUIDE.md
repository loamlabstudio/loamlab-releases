# 📸 LoamLab IG 聯名推廣（Collabs）操作手冊

歡迎與 LoamLab 進行 Instagram 聯合發文（Collab）！這份手冊教您如何解決 IG「內文連結無法點擊」的痛點，並說明聯名前必須知道的免責聲明。

---

## 🚧 核心痛點：IG 貼文內文連結點不了

Instagram 的貼文說明文字（caption）**不支援可點擊連結**，只有個人主頁的「連結」欄位可以放一個網址。這代表：
- 貼文裡放 `https://loamlab.studio` 或您的專屬邀請連結，粉絲**看得到但點不到**。
- 硬要他們手動輸入網址，轉換率會非常差。

## ✅ 建議解法：用留言自動回覆機制（例如 ManyChat）取代內文連結

**強烈建議**在貼文中改用「引導留言」的方式，並串接 [ManyChat](https://manychat.com)（或同類 IG 自動回覆工具）：

1. 貼文文案改寫成：「留言『渲染』兩個字，我私訊你下載連結和專屬邀請碼！」
2. 在 ManyChat 設定關鍵字自動化：只要有人在該貼文下留言指定關鍵字（例如「渲染」），機器人會**自動私訊**該粉絲：
   - LoamLab 插件下載連結
   - 您的專屬邀請碼（在插件內「頭像 → 邀請碼」輸入即可綁定，雙方各得獎勵點數）
3. 好處：私訊裡的連結可以直接點擊，繞開 IG 內文連結限制，且互動（留言數）還能幫貼文提高演算法權重。

> 沒有 ManyChat 也沒關係，退而求其次的作法是把連結放在您的 IG 個人主頁「連結」欄位，並在貼文文案提醒「連結在主頁」。但轉換率會明顯低於自動回覆機制，能設定的話務必優先使用。

## ⚠️ 聯名免責聲明（送出前請詳閱）

提交 LoamLab 聯名推廣（Collab）申請或發佈聯名貼文，即表示您同意以下條款：

1. **原創保證**：您保證貼文中使用的所有素材（含渲染圖、設計方案、模型）皆為您本人原創或已取得合法授權，不侵犯任何第三方著作權。
2. **版權爭議處理**：若貼文內容遭第三方檢舉或證實有版權爭議，**LoamLab 官方有權單方面解除本次 Collab 關係**（包含但不限於下架聯名標記、移除官方帳號的共同發佈狀態）。
3. **獎勵收回**：發生前項爭議時，LoamLab 有權**收回因本次聯名已發放的獎勵點數**，不另行通知。

若對條款有疑問，請於提交聯名申請前先與官方聯繫確認。
